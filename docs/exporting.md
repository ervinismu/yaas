# Exporting

Both exports save a file next to the note, and leave out speaker notes. Export again after changing the slides; the old file is replaced.

## PDF

Click ⬇ in the slides panel, or run **Export this note as a PDF**.

- Landscape, one slide per page (16:9).
- Looks the same as on screen.
- Small: a deck is usually a few hundred KB.

## HTML

Run **Export this note as one HTML file**. You get a single file with everything inside, including images. Anyone can open it in a browser, offline, and click through the slides.

Use it when someone else should present the deck.
